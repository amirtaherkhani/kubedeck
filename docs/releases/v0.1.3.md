# KubeDeck v0.1.3 release notes draft

Status: prepared on 2026-10-05; the `v0.1.3` tag and GitHub Release have not
been created.

## Release target

The verified application source release commit is
`1b7ce2e89dcd5e759609aac9e3124a2f35c1060a`, the merge commit for PR #15
([`Prepare KubeDeck 0.1.3 release`](https://github.com/amirtaherkhani/kubedeck/pull/15)).
It updates the dashboard package, dashboard and agent Helm chart metadata, and
README image examples to `0.1.3`.

The PR #15 snapshot includes earlier merged repository changes, including the
platform KEDA and storage configuration from PR #14 and the migration roadmap
documentation from PR #17. The notes below describe the dashboard and agent
release highlights; they do not claim those other files are absent from the
tagged repository snapshot.

This target predates PR #19's `my-home-lab/` to `lab/` rename
([PR #19](https://github.com/amirtaherkhani/kubedeck/pull/19), merged at
`9348cb4b6dc809b65915dbbd98712583dccff8ee`). The rename is not in the original
v0.1.3 source commit, but it is part of current main and will be present in a
later tag made from current main. A source comparison from PR #15 to PR #19
found no changes in the dashboard or agent runtime source paths; the later
changes are repository path, docs, and layout-test changes.

The final tag target is not set here. The release guide requires a dated
v0.1.3 entry in the root changelog before tagging. Add that entry when the
release date is approved, then tag the resulting main merge commit. That tag
will include the `lab/` rename and other repository-level changes now in main.
Do not describe a later main snapshot as the PR #15 source commit.
