# v0.2.1

## Highlights

- Restore Grafana, Prometheus Stack, Loki, Tempo, Alloy, and k6 Operator as managed Docker Desktop Kubernetes releases.
- Keep the Grafana image renderer, Prometheus Operator and exporters, Tempo metrics generation, and dashboard provisioning in the observability deployment.

## Fixed

- Disable anonymous Grafana administrator access.
- Resolve Grafana's Infisical project and environment from the active Docker Desktop scope.
- Remove the obsolete Rancher Desktop scrape target and use the current Docker Desktop storage class.

## Migration

- Deploy the six restored releases in the order listed in `lab/core/helm/releases.conf`.
- Grafana expects `GRAFANA_ADMIN_USER` and `GRAFANA_ADMIN_PASSWORD` in Infisical at `/apps/observability/grafana`.
- The k6 Operator installs only the controller; load tests remain opt-in.
